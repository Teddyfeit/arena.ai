# arena.ai

## What's in here

- `index.html` — ARENA//RTX: a single-file, real-time ray-traced WebGL showcase. Open it in any browser — it's fully self-contained.
- `roblox/RTXSetup.server.luau` — ARENA//RTX for Roblox: a drop-in server Script that applies a cinematic "raytraced" lighting profile and traces real rays for one-bounce GI. Install steps: `roblox/README.md`.
- `test.py` — Roblox Avatar Finder. Start it with `python test.py` (opens http://localhost:8000).
