# FIELDKIT

FIELDKIT combines the **Roblox Avatar Finder** and **Discord Name Radar** in one workspace: the Avatar Finder opens first, and Name Radar is available as a tab in the same sidebar.

```bash
python tool_hub.py
```

It opens at `http://127.0.0.1:8765`. Use Python's standard library only. For an Arena/sandbox preview:

```bash
python tool_hub.py --host 0.0.0.0 --port 8002 --no-browser
```

Discord Name Radar is a manual username watchlist with priorities, notes, settings and reminders. It does not query Discord, automate username changes, or store Discord credentials/tokens.
